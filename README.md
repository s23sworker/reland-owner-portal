# Reland — Кабінет власника (Owner Portal)

Особистий кабінет власника комерційної нерухомості: бази → блоки → орендарі,
актуальні ринкові ставки і кнопки, якими власник просить нас здати приміщення,
перевірити попит або знайти нового орендаря.

Основне середовище — **Telegram Mini App**. Та сама збірка відкривається і як
звичайна веб-сторінка (fallback по magic-link), тому все, що стосується Telegram,
живе в `src/telegram.ts` і мовчки нічого не робить поза Telegram.

## Статус

Візуальний макет на тимчасових даних. Бекенда ще немає.

- `src/mock.ts` — дані Валентина (реальні об'єкти з CRM + вигадані блоки й ставки).
  Коли з'явиться API, файл видаляється, форма даних лишається та сама.

## Запуск

```bash
cd frontend
npm install
npm run dev      # http://localhost:3004
```

## Зв'язок із CRM

CRM — єдине джерело даних. Кабінет нічого не рахує сам: ні PRIME-статус,
ні групування об'єктів у бази, ні ринкову ціну. Він показує готову проекцію,
яку складає CRM, і пише назад лише заявки власника (натискання кнопок).

Деталі й покроковий план — у CRM-репозиторії:
`docs/specs/owner-portal/README.md`.
